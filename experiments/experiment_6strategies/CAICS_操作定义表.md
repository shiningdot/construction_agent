# CAICS 操作定义表 (Operational Definition)

> 对标 Liu et al. (ESWA 2025) Table 1 — Question Set and Response Instructions

## M层: 管理根基 (Management Foundation) — 系统性安全管理缺陷

| Code | Category | 操作定义 | 典型证据 (Keywords from Text) | 数据频率 |
|------|---------|---------|---------------------------|:--:|
| M1 | 现场监管缺失 | 施工现场安全监督力量未有效覆盖关键作业面，监理/安全员未能在事故发生前发现并制止不安全状态 | "无人监管""监理失职""安全管理混乱""未及时发现制止""现场无安全员" | ⭐⭐⭐ |
| M2 | 隐患排查失效 | 组织建立了隐患排查制度要求，但执行层面未能识别已存在的危险源，或识别后未在规定时间内整改关闭 | "未排查""未整改""隐患长期存在""未进行风险评估""检查走过场" | ⭐⭐⭐ |
| M3 | 安全培训不足 | 作业人员或管理人员未接受与岗位风险相匹配的安全培训，或培训内容与实际作业脱节，导致缺乏必要的安全知识和应急能力 | "未经培训""安全交底不到位""交底走过场""缺乏安全知识""三级教育不足" | ⭐⭐ |
| M4 | 制度规程漏洞 | 安全管理制度、施工方案、操作规程、应急预案缺失、不完备、或未能覆盖实际施工场景中的风险点 | "无安全方案""应急预案缺失""制度不健全""无施工方案""未编制专项方案" | ⭐⭐ |
| M5 | 市场行为违规 | 参建单位通过违法分包、转包、挂靠、无资质或超资质承揽、违规压缩工期等市场行为，系统性地降低了安全管理投入和质量 | "违法分包""无资质""转包""抢工期""未办理报建""挂靠""出卖资质" | ⭐ |

## F层: 防线失效 (Protection Failure) — 物理屏障/防护的缺失或失效

| Code | Category | 操作定义 | 典型证据 (Keywords from Text) | 数据频率 |
|------|---------|---------|---------------------------|:--:|
| F1 | 临边洞口防护缺失 | 施工区域的临边（楼层边缘、阳台等）、洞口（电梯井、预留孔洞等）未按规范设置防护栏杆、安全网、盖板等防坠落设施 | "无防护""无护栏""临边未设防""洞口未盖""未设置安全网""防护栏杆缺失" | ⭐⭐⭐ |
| F2 | 支撑体系失稳 | 模板支撑系统、脚手架、基坑支护等临时结构在设计、搭设、使用或拆除过程中，因承载力不足、构造缺陷或违规操作导致失稳或坍塌 | "模板坍塌""脚手架失稳""支撑不足""支架倒塌""未按方案搭设""扣件松动" | ⭐⭐⭐ |
| F3 | 设备安全装置失效 | 塔吊、施工升降机、物料提升机等特种设备的安全限位器、防坠器、力矩限制器、保险装置被人为屏蔽、损坏或未安装 | "限位器被屏蔽""防坠器失效""安全装置损坏""保险装置失灵""力矩限制器缺失" | ⭐ |
| F4 | 个体防护未使用 | 作业人员在危险作业环境中未按规定佩戴或使用安全帽、安全带、防滑鞋、防护手套等个人防护装备(PPE) | "未系安全带""未戴安全帽""无防护用品""未使用PPE""安全带未挂点" | ⭐⭐ |

## T层: 触发条件 (Trigger Conditions) — 直接触发事故的物质或环境条件

| Code | Category | 操作定义 | 典型证据 (Keywords from Text) | 数据频率 |
|------|---------|---------|---------------------------|:--:|
| T1 | 设备机具故障 | 施工机械、设备、机具在运行过程中发生不可预期的故障、断裂、失灵等机械失效，直接导致或加速了事故的发生 | "设备故障""塔吊倒塌""钢丝绳断裂""机械失灵""升降机故障""制动失效" | ⭐⭐ |
| T2 | 物料状态异常 | 施工材料、构件、堆载物因自身性质变化(浸水、老化、变质)或外部因素(超载、偏载)导致状态不稳定，引发结构失效或物体打击 | "堆载超限""材料缺陷""荷载过大""物料失稳""珍珠岩浸水""瓦斯积聚""混凝土未干透" | ⭐⭐⭐ |
| T3 | 地质环境突变 | 施工区域的地质条件(土体、岩层)或地下水状态发生突变，如涌水、流沙、边坡滑动、地基突然沉降等 | "涌水""边坡失稳""地基沉降""基坑坍塌""土体滑移""流沙""突泥" | ⭐⭐ |
| T4 | 气象水文触发 | 暴雨、大风、冰雪、雷电、高温等极端天气条件直接触发了事故，或显著降低了结构/防护的安全性 | "暴雨""大风""冰雪""雷电""六级风""连日降雨""高温""台风" | ⭐ |

## H层: 人的行为 (Human Acts) — 直接导致事故的人为行为

| Code | Category | 操作定义 | 典型证据 (Keywords from Text) | 数据频率 |
|------|---------|---------|---------------------------|:--:|
| H1 | 违反操作规程 | 作业人员的行为明确违反了已制定的施工方案、安全操作规程、技术规范或法律法规要求 | "未按方案放坡""违反操作规程""擅自变更施工方案""违规拆除""未按规范搭设" | ⭐⭐⭐ |
| H2 | 违规指挥决策 | 管理人员(项目经理、工长、班组长等)在明知存在安全风险的情况下，仍然发出指令要求工人继续或冒险作业 | "强令冒险作业""明知风险仍施工""违章指挥""要求工人冒险进入""负责人下令继续施工" | ⭐⭐ |
| H3 | 风险辨识失败 | 作业人员或管理人员未能识别作业环境中存在的危险，或对危险程度评估不足，表现为"没意识到""疏忽大意""判断失误" | "未意识到危险""安全意识薄弱""未检查确认""疏忽大意""以为没问题""低估了风险" | ⭐⭐ |
| H4 | 应急行为失当 | 事故发生后，现场人员在应急救援过程中的不当行为导致伤亡扩大，如盲目施救、未及时撤离、救援方法错误等 | "盲目施救""未及时撤离""救援不当导致伤亡扩大""二次坍塌时仍在施救""未呼救先自行处置" | ⭐ |

## C层: 后果放大 (Consequence Amplification) — 使事故后果超出预期的因素

| Code | Category | 操作定义 | 典型证据 (Keywords from Text) | 数据频率 |
|------|---------|---------|---------------------------|:--:|
| C1 | 救援响应迟缓 | 从事故发生到有效救援到达的时间间隔过长，或救援过程因缺乏预案、设备不足、组织混乱等原因效率低下 | "救援不及时""无预案""二次坍塌""延误抢救""救援力量不足""救援设备缺乏" | ⭐ |
| C2 | 信息迟报瞒报 | 事故发生后，责任单位未按规定及时向上级主管部门报告，或故意隐瞒、延迟报告事故信息，导致外部支援无法及时介入 | "未及时上报""瞒报""迟报""漏报""未按规定报告""拖延上报" | ⭐ |
