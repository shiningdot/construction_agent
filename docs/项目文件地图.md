# CAIEMS 项目文件地图（端到端）

> 论文题目是端到端管道，本文件按 **源头 → 采集 → 清洗筛选 → 提取编码 → 存储 → 展示 → 论文** 的顺序，
> 说明每个阶段的数据落在哪个目录、由哪个脚本产生、下一步流转到哪里。
>
> 建立日期：2026-09-28 ｜ 对应数据库口径：2,623 条事故 · 16,323 条致因编码

---

## 一、总览

项目有**两个物理位置**，职责不同：

| 位置 | 相对家目录路径 | 内容 |
|---|---|---|
| 主仓库 | `construction_agent/` | 项目代码 + `data/`（含主数据库）+ 实验与脚本 |
| worktree | `construction_agent/.claude/worktrees/classifier-mod/` | 论文稿件 + 论文脚本 + 消融实验数据 |

> ⚠️ worktree 里也有一套 `construction_agent/`、`docs/`、`scripts/`，那是 git 分支检出带来的副本。
> **判据：代码与数据库以主仓库为准；论文与论文实验以 worktree 为准。**

端到端流转：

```
① 源头            ② 采集            ③ 清洗筛选         ④ 提取编码        ⑤ 存储            ⑥ 展示
asset/ebook ─┐
Input-PDF  ──┤                  collector/        cleaners/       extraction/      data/            web/
collector_  ─┼─→ collector/sources ─→ 清洗 → classifier ─→ step1+step2 ─→ caiems_v2.db ─→ Flask 平台
sources/    ─┘   （25 个适配器）   四器      （两道闸门）  （33字段+编码）   （9 表）           + REST API
                                                            ↓
                                                    ⑦ 论文与实验（worktree）
                                              experiments/ → docs/paper_v2/ → 四格式成品
```

## 四、③ 清洗与筛选：怎么挑

两道闸门 + 四类清洗器，都在 `construction_agent/collector/`：

| 路径 | 作用 |
|---|---|
| `collector/cleaners/text_cleaner.py` | 正文清洗（去导航/广告/空白） |
| `collector/cleaners/field_extractor.py` | 正则预抽取（日期/地点/伤亡数） |
| `collector/cleaners/normalizer.py` | 字段归一化（省份、日期格式） |
| `collector/cleaners/deduplicator.py` | 四层去重 |
| `collector/classifier.py` | 闸门一：关键词相关性筛选 |
| `collector/llm_classifier.py` | 闸门二：LLM 文本三分类（single / multi / other） |

分类体系与归一化规则：`data/taxonomy/taxonomy.json`、`data/taxonomy/normalization_rules.json`。

## 十、路径依赖与红线（**不可移动**）

以下位置被代码硬编码引用，移动会导致管道失效：

| 约束 | 依据 |
|---|---|
| `construction_agent/` 包与 `data/` 的相对位置 | `construction_agent/config.py`：`DATA_DIR = Path(__file__).resolve().parents[1] / "data"` |
| `.env` 必须在 `construction_agent/` 上一级 | 同上：`env_path = Path(__file__).resolve().parents[1] / ".env"` |
| `data/datasets/accidents_merged.json` | `config.py`：`DATASET_FILE` |
| `data/caiems_v2.db` | `config.py`：`DATABASE_URL` 默认值 |

**结论：本轮整理不移动任何既有文件**，只做"标注 + 说明 + 修正过期信息"。
如需物理重组目录，必须同步修改 `config.py` 并回归测试管道。
