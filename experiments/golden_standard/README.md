# Golden Standard 候选集（CAICS 致因标注标准答案的取样前端）

从 `data/caiems_v2.db`（2601 条）中筛出 **300 条**「原始文本详细、事故信息丰富、致因多」的事故，
作为交给强模型做 CAICS 5 层 19 类致因标注、再经人工核对形成标准答案的输入。

生成脚本：`scripts/screen_golden_candidates.py`

```bash
python3 -I scripts/screen_golden_candidates.py --diagnose          # 看各来源通过率
python3 -I scripts/screen_golden_candidates.py --select --top 300  # 生成候选集
```

## 筛选判据

1. **来源池**：`report_type ∈ {事故调查报告, 政府通报, 教材案例}`，排除新闻报道（记者稿无官方原因认定）。
2. **原因认定段落（硬性）**：正文必须含「直接原因/间接原因/主要原因/事故原因/原因分析」。
   没有原因认定 = 无法做致因标注。已剔除目录行干扰，避免用目录里的"事故原因……8"蒙混通过。
3. **文本洁净度**：先剔除页码、目录点线、抓取元信息、**网页导航壳**（标题/关键字/摘要/全文/首页/您当前的位置…）等版式行，
   再算碎片短行占比，>0.18 判为扫描件 OCR 交错。另剔乱码字符与中文占比 <0.60 的记录。
4. **单事故完整性**：按**不同案例编号**计数识别「一条记录塞多起事故」的合并块，
   且要求第二起事故后确实有 ≥300 字正文才算（同篇页眉/交叉引用不误伤）。
   ⚠️ 另有 800 例专用判据：`发生(事故)?[简高]况` 是该书**每起事故一条**的字段标签，
   出现 ≥2 次即多起事故——首轮漏了这条，导致 51 条合并块混入（详见 `S1_result/README.md` 返工记录）。
5. **致因丰富度打分**：原因段落陈述句条数 0.30 + 跨层（M/F/T/H/C）关键词覆盖 0.25 + 篇幅 0.15
   + DB 字段填充数 0.15 + 原因层级种类 0.10 + 枚举式致因数 0.10。

## 关键发现（决定候选池取哪些来源）

| 来源 | 条数 | 可用性 |
|---|---|---|
| 住建部《建筑施工安全事故案例分析》 | 50 | ✅ 100% 含原因段，98% 文本完整收尾 |
| 住建部《…（扫描版）》 | 88 | ✅ 100%，98.9% 完整收尾 |
| 住建部《建筑施工生产安全事故案例分析》 | 43 | ✅ 100%，100% 完整收尾 |
| 《建筑施工重大伤亡事故800例》 | 703 | ✅ 99.9% 带「直接/间接/主要原因」标签，94% 完整，但条目偏短（中位 586 字） |
| esafety | 388 | ❌ **扫描件 OCR 双栏交错**，如"上午，施工人员将事发2023各日技术>风，头安全\|底"；且截断在 ~3200 字，29% 无原因段 |
| 各地应急局 `*_em` | ~90 | ❌ **被截断**：raw_text 尾部带「(共N字)」标记，原文均 7883 字，实际仅得 ~3066 字；抽查有停在半句中间的 |
| safehoo | 1237 | ❌ 新闻报道，41% 提到原因但无官方原因认定 |

> 结论：**候选池只用书籍来源**（住建部三本 + 800例）。网页来源整体降级到 T3，
> 补救路径是按 raw_text 里保留的 `PDF: https://…` 链接重抓原文（不是无解，但属于另一步工作）。

## 分档

- **T1_core（160 条入选）**：篇幅 ≥1200 字且「直接原因 + 间接原因」结构齐全 —— 主力标准答案来源
- **T2_short（140 条入选）**：500–1200 字，含显式原因标签 —— 补充来源
- **T3_hold**：截断 / OCR 交错 / 无原因段 / 合并块 / 网页来源

## 后续流程（标准答案制定）

1. 用强模型对 300 条做特征提取（Step1 的 33 字段）+ CAICS 致因标注（Step2，M1-M5/F1-F4/T1-T4/H1-H4/C1-C2，每类附原文证据）
2. 人工核对每条编码的证据是否落在原文（`evidence` 必须可回溯）
3. 争议条目三人标注取多数（可复用 `scripts/recover_gt.py` 的 Fleiss κ 流程）
4. 冻结为标准数据集，用于评测 Step1/Step2 及各策略

## 已知偏差

- 候选池 100% 来自书籍（2008–2017 年案例为主），**年代偏老**；若需要近年样本，须先解决网页来源的截断问题（重抓 PDF）。
- 800例 条目虽带完整原因标签，但正文短，作为"文本详细"的样本成色弱于 T1。
