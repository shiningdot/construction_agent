# 论文用 17 编码 F1 / 召回率三线表（Letter 纵向，15.20 cm）

## 1. 为什么不是 16 cm

论文稿 `paper/eswa_paper_10.22` 的实际版面是：

| 项 | 值 |
|---|---|
| 纸张 | Letter，21.59 × 27.94 cm |
| 左右页边距 | 3.17 cm |
| **正文可用宽度** | **15.24 cm** |
| 上下页边距 | 2.54 cm |
| 分栏 | 单栏 |

因此表宽按 **15.20 cm** 设计；16 cm 的表插入后仍会溢出。

## 2. 两张表

| 指标 | 文件 | 说明 |
|---|---|---|
| F1 | `f1_three_line_portrait.docx` | 主表，F1（%） |
| 召回率 Recall | `recall_three_line_portrait.docx` | 同版式，召回率（%） |

两张表结构完全相同：

- **删除后果放大层（C1、C2）**，只保留 M/F/T/H 四层 **17 个编码**。
- 20 列 × 26 行：2 行表头 + 4 模型 × 6 策略 = 24 行数据。
- 双层表头：
  - 第一行：`模型`、`提示`、`管理 M`（跨 M1–M5）、`防线 F`（跨 F1–F4）、
    `触发 T`（跨 T1–T4）、`行为 H`（跨 H1–H4）、`Ave(17)`；
  - 第二行：17 个编码。
- 模型名在模型列纵向合并 6 行，分四块：GLM-5.2、DeepSeek-V4-Flash、
  混元 hy3、DeepSeek-V4-Pro。
- 三线：顶线 1.5 pt、表头下线 0.75 pt、底线 1.5 pt；无竖线；
  模型组之间加 0.25 pt 浅灰细线（可在 Word 中删除）。
- 每列跨 24 行比较，最优加粗、次优下划线（并列全部标记）。

## 3. 列宽与字号

| 列 | 数量 | 单列宽 | 小计 |
|---|---:|---:|---:|
| 模型 | 1 | 1.55 cm | 1.55 cm |
| 提示 | 1 | 2.12 cm | 2.12 cm |
| 编码 M1–H4 | 17 | 0.615 cm | 10.455 cm |
| Ave(17) | 1 | 1.08 cm | 1.08 cm |
| **合计** | **20** | | **15.205 cm** |

- 数值：**7 pt，保留 1 位小数**；Times New Roman。
- 表头：编码 6.5 pt 加粗；层组 6.0 pt 加粗；模型/提示 7 pt。
- 表题：10.5 pt 宋体加粗；表注：7 pt 宋体。
- 行高：数据行 0.48 cm 固定值；表头行 0.42 cm。
- 单元格左右边距：**0**（关键；默认 0.19 cm 会把 0.615 cm 列挤到换行）。

### 为什么用 1 位小数

召回率表有大量 `100.00`。在 0.615 cm 列宽、7 pt 下，`100.00` 约 0.66 cm，
会与相邻列重叠；改为 1 位小数后 `100.0` 约 0.56 cm，留有约 0.06 cm 间隙。
F1 与召回率统一用 1 位小数，保证两张表版式一致；
完整的 2 位小数仍保留在 `../f1_per_code.csv`。

若期刊强制要求 2 位小数，可把脚本中的 `DECIMALS = 2`、`BODY_FONT_PT = 6.5`，
但召回率的 `100.00` 会非常拥挤，建议改用横向页或分表。

## 4. 指标口径

```
F1(code)     = 2TP / (2TP + FP + FN)
Recall(code) = TP / (TP + FN)
Ave(17)      = mean(指标[M1..M5], 指标[F1..F4], 指标[T1..T4], 指标[H1..H4])
```

- 两张表的 `Ave(17)` 分别是 17 类 **F1** / 17 类 **召回率** 的未加权宏平均。
- 表中 **不显示 C1、C2**；它们仍保留在 `../f1_per_code.csv` 中，便于备查。
- C1 有 40 个 GT 正例，C2 只有 2 个，指标波动大，故不进入本表与 Ave(17)。
- CSV 中同时保留：
  - `Ave`：19 类 F1 宏平均；
  - `Ave+`：排除 C2 的 18 类 F1 宏平均；
  - `Ave17`：排除 C1、C2 的 17 类 F1 宏平均；
  - 每类 `*_R`：该编码的召回率（本表召回率的来源）。
- 排除 C1/C2 后，混元 hy3 的 F1 最优策略由原来的 S4 变为 S5
  （Ave17：S5 = 77.48，S4 = 76.10），正文需说明口径差异。

## 5. 插入 Word 的步骤

1. 打开对应 DOCX，选中整张表（含表题和表注）复制。
2. 在论文稿中定位到插入点，**选择性粘贴 → 保留源格式**。
3. 若表格被撑宽：
   - 右键表格 → 表格属性 → 表格 → 指定宽度 **15.2 cm**，布局“固定”；
   - 表格属性 → 单元格 → 选项 → 左/右边距 **0 cm**；
   - 表格属性 → 行 → 指定高度 0.48 cm，行高值“固定值”，取消“允许跨页断行”；
   - 检查表头两行是否勾选“在各页顶端以标题行形式重复出现”。
4. 若论文模板的表格样式带蓝色网格，选中表格 → 表格设计 → 边框 →
   清除全部边框，再按“上框线 1.5 pt / 表头下线 0.75 pt / 下框线 1.5 pt”重设；
   本文件的单元格边框是直接格式，通常粘贴后会保留。
5. 把表题中的 `表 X` 改成论文实际编号；两张表建议连续编号（如 Table 5、Table 6）。
