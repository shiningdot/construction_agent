# work_task 施工作业类型枚举定义

## 概述

- **字段名**: `work_task`
- **用途**: 记录事故发生时的具体施工作业类型
- **编码规则**: `WT` + 两位数字 + `-` + 中文名称
- **类别数**: 15 类（含"其他"）
- **设计原则**:
  - 按施工工艺和作业特征分类，而非按工程部位
  - 设备/工法的全生命周期（安装→使用→拆除）归入同一类别
  - 无法明确归入前14类的归入 WT15

---

## 枚举值详细定义

### WT01 - 土方与基坑
**覆盖范围**: 土方开挖、回填、基坑支护、边坡处理、沟槽开挖、地基处理  
**关键词**: 土方、基坑、沟槽、开挖、回填、边坡、地基、挖土、挖方、深基坑、降水  
**包含**:
- 土方开挖/回填作业
- 基坑支护（排桩、地下连续墙、水泥土墙、土钉墙等）
- 沟槽开挖（管沟、排水沟等）
- 边坡处理/加固
- 地基处理（强夯、换填、预压等，不含桩基）
- 基坑降水/排水
**不包含**:
- 桩基施工 → WT02
- 管道铺设（即使涉及沟槽开挖，以主要目的为准） → WT11
**典型示例**: 土方开挖、挖地基、沟槽开挖、基坑施工、深基坑开挖、土方回填、地基施工

### WT02 - 桩基工程
**覆盖范围**: 各类桩基础的施工（预制桩、灌注桩、搅拌桩等）  
**关键词**: 桩、打桩、灌注桩、预制桩、管桩、搅拌桩、CFG桩、钻孔桩、压桩  
**包含**:
- 预制桩施工（锤击、静压、振动）
- 灌注桩施工（钻孔、冲孔、旋挖）
- 水泥土搅拌桩、CFG桩、碎石桩
- 桩基检测（静载试验、低应变检测等）
**典型示例**: 打桩作业、桩基施工、钻孔灌注桩施工、静压管桩施工、CFG桩施工

### WT03 - 钢筋工程
**覆盖范围**: 钢筋的加工、绑扎、连接、安装  
**关键词**: 钢筋、绑扎、绑钢筋、钢筋笼、钢筋网、钢筋加工、直螺纹、焊接钢筋  
**包含**:
- 钢筋绑扎/安装
- 钢筋加工（调直、切断、弯曲）
- 钢筋连接（焊接、机械连接、绑扎搭接）
- 钢筋笼制作/吊装
- 预应力钢筋张拉
**不包含**:
- 钢结构安装 → WT06
**典型示例**: 绑钢筋、绑扎钢筋、钢筋网施工、钢筋笼吊装、钢筋加工

### WT04 - 模板与支撑
**覆盖范围**: 模板、支撑架、操作平台、满堂架的搭设与拆除  
**关键词**: 模板、支模、拆模、支撑架、支模架、满堂架、排架、操作平台、模板支撑  
**包含**:
- 模板搭设/拆除
- 支撑体系搭设/拆除（含高支模、爬模、滑模）
- 操作平台/施工作业平台搭设
- 满堂脚手架/承重支撑架（即使名称含"脚手架"，承重属性优先）
- 爬架/附着式升降脚手架（作业平台属性强于防护属性时归此类）
**不包含**:
- 外脚手架/防护用脚手架 → WT07
**典型示例**: 模板施工、支模架搭设、拆除模板、拆模作业、搭设操作平台、支设模板

### WT05 - 混凝土浇筑
**覆盖范围**: 混凝土的搅拌、运输、浇筑、振捣、养护  
**关键词**: 混凝土、浇筑、浇灌、浇注、浇捣、振捣、泵送、混凝土搅拌、封顶、现浇  
**包含**:
- 混凝土浇筑/振捣
- 混凝土搅拌/运输
- 混凝土泵送
- 混凝土养护
- 预制混凝土构件安装（楼梯、楼板、墙板等）
- 大体积混凝土施工
- 封顶施工（主体结构混凝土封顶）
**不包含**:
- 桥墩/桥梁混凝土施工 → WT09（以桥梁工程属性优先）
**典型示例**: 浇筑混凝土、混凝土浇筑、混凝土浇灌、浇灌混凝土、封顶施工、泵送混凝土

### WT06 - 钢结构与网架
**覆盖范围**: 钢结构、网架、桁架、幕墙骨架的安装与施工  
**关键词**: 钢结构、钢网架、网架、桁架、钢柱、钢梁、钢屋架、彩钢板、钢构  
**包含**:
- 钢结构安装（钢柱、钢梁、钢桁架）
- 网架/网壳安装（高空散拼、整体吊装、整体提升）
- 轻钢结构/彩钢板安装
- 钢屋盖/钢屋架安装
- 钢结构焊接/高强螺栓连接
**不包含**:
- 钢筋工程 → WT03
- 塔吊钢结构 → WT08
**典型示例**: 钢结构施工、钢网架高空散拼安装、钢屋架吊装、网架安装

### WT07 - 脚手架作业
**覆盖范围**: 外防护脚手架、操作脚手架的搭设、使用、拆除全生命周期  
**关键词**: 脚手架、脚手板、外架、脚手、扣件式、碗扣式、盘扣式、悬挑架  
**包含**:
- 外脚手架搭设/拆除
- 悬挑脚手架施工
- 脚手架维护/改造
- 防护棚搭设（如安全通道防护棚）
- 卸料平台搭设
**不包含**:
- 模板支撑架/满堂承重架 → WT04
- 爬架（附着式升降脚手架）→ WT04
**典型示例**: 脚手架作业、搭设脚手架、脚手架施工、脚手架拆除、外脚手架搭设

### WT08 - 塔吊与起重
**覆盖范围**: 塔式起重机、施工升降机、物料提升机、汽车吊等起重设备的安装、顶升、使用、拆卸全生命周期  
**关键词**: 塔吊、塔式起重机、起重机、起重、吊车、吊装、吊运、顶升、龙门架、井架、卷扬机、架桥机  
**包含**:
- 塔吊安装/拆卸/顶升
- 塔吊吊运/吊装作业
- 施工升降机/物料提升机安装/使用/拆卸
- 汽车吊/履带吊等移动式起重机吊装
- 龙门架/井架安装/使用/拆除
- 卷扬机/电动葫芦起重作业
- 架桥机作业
**不包含**:
- 桥梁墩柱/箱梁混凝土施工 → WT09
**典型示例**: 塔吊作业、塔吊顶升作业、塔吊安装、拆除塔吊、塔吊吊运作业、安装龙门架

### WT09 - 桥梁工程
**覆盖范围**: 桥梁主体结构的施工作业（墩台、箱梁、桥面等），以工程类型属性优先  
**关键词**: 桥梁、桥墩、桥面、箱梁、T梁、墩柱、盖梁、桥台、预制梁  
**包含**:
- 桥墩/桥台施工
- 箱梁/T梁预制/架设
- 桥面铺装/护栏施工
- 悬索桥主缆/吊索施工
- 斜拉桥索塔/斜拉索施工
- 拱桥拱圈施工
**不包含**:
- 桥梁拆除 → WT13
- 架桥机作业（以起重设备操作为主） → WT08
**典型示例**: 桥梁施工、桥墩施工、桥墩混凝土浇筑、箱梁施工

### WT10 - 隧道与地下
**覆盖范围**: 隧道、地下管廊、地下通道的掘进与支护  
**关键词**: 隧道、隧洞、掘进、管廊、地下、暗挖、顶管、盾构、TBM  
**包含**:
- 隧道开挖/掘进
- 隧道支护（锚喷、衬砌、管片安装）
- 盾构/TBM施工
- 顶管施工（非开挖管道铺设）
- 地下综合管廊施工
- 暗挖法施工
**不包含**:
- 明挖管道沟槽 → WT01（以沟槽开挖为主要特征）
**典型示例**: 隧道施工、隧道掘进施工、隧道开挖施工、顶管施工、盾构施工

### WT11 - 管道与管网
**覆盖范围**: 给排水、燃气、热力、电力等市政管道的安装与改造  
**关键词**: 管道、管网、管线、给排水、排水管、污水管、供水管、燃气管、暖通、试压  
**包含**:
- 管道铺设/安装
- 管道焊接/连接
- 管道试压/检测
- 管道改造/维修（市政管网级别）
- 排水管网/供水管网施工
**不包含**:
- 沟槽开挖（即使是管道的沟槽）→ WT01
- 建筑物内部给排水管道 → WT12
- 顶管施工（非开挖）→ WT10
**典型示例**: 污水管网施工、自来水管道改迁打压、管道铺设

### WT12 - 装饰与装修
**覆盖范围**: 建筑物的内外装饰、装修、防水、保温、幕墙等作业  
**关键词**: 装修、装饰、抹灰、粉刷、涂料、油漆、贴砖、防水、保温、幕墙、门窗、玻璃  
**包含**:
- 内外墙抹灰/粉刷/涂料
- 外墙面砖/石材干挂
- 玻璃幕墙/石材幕墙安装（含龙骨安装）
- 屋面防水/保温施工
- 外墙外保温施工
- 门窗安装
- 室内装饰装修
- 建筑物内部给排水管道/暖通安装
**典型示例**: 装修施工、抹灰作业、外墙保温施工、外墙涂料施工、外墙抹灰、安装玻璃、外立面装修

### WT13 - 拆除作业
**覆盖范围**: 建筑物、构筑物、结构构件的拆除/爆破  
**关键词**: 拆除、拆迁、拆房、拆楼、拆墙、爆破拆除、机械拆除  
**包含**:
- 房屋/建筑物整体拆除
- 墙体/楼板/梁柱等结构构件拆除
- 构筑物拆除（烟囱、水塔、冷却塔等）
- 爆破拆除
- 保护性拆除/改造拆除
**不包含**:
- 脚手架拆除 → WT07（全生命周期原则）
- 塔吊/起重设备拆除 → WT08（全生命周期原则）
- 模板拆除 → WT04（全生命周期原则）
- 支撑架拆除 → WT04（全生命周期原则）
**典型示例**: 拆除作业、拆迁施工、拆除墙体、房屋拆除、建筑拆除作业

### WT14 - 设备安装
**覆盖范围**: 建筑机电设备、工业设备、专用设备的安装调试（不含起重设备）  
**关键词**: 设备安装、机电安装、电梯安装、调试、设备调试、电气安装、暖通安装  
**包含**:
- 电梯/自动扶梯安装
- 变配电设备安装
- 空调/暖通设备安装
- 消防设备/管道安装
- 工业设备安装
- 设备调试
**不包含**:
- 塔吊/龙门架/井架等起重设备 → WT08
- 模板/支撑/脚手架 → WT04/WT07
**典型示例**: 设备安装、电梯安装、电气设备安装、通风管道安装

### WT15 - 其他
**覆盖范围**: 无法归入以上14类的施工作业、辅助性作业、或信息不足以判断的作业  
**关键词**: 维修（建筑）、巡查、测量、检测、清洁、绿化、临建  
**包含**:
- 施工现场辅助作业（清理、抽水、搬运材料等）
- 临时设施搭建（活动板房、围挡、临时道路）
- 测量放线
- 质量检测/试验
- 现场绿化/景观施工
- 多工种混合且无法判断主要作业类型
**典型示例**: 现场清理、抽水作业、临时设施搭建、测量放线

## 边界判定规则

### 规则1：设备/工法全生命周期原则
某项设备/工法的安装、使用、拆除均归入同一类别：
- 塔吊安装/顶升/使用/拆除 → 全部归 WT08
- 脚手架搭设/使用/拆除 → 全部归 WT07
- 模板搭设/使用/拆除 → 全部归 WT04

### 规则2：设备类型优先原则
当自由文本同时描述设备和作业内容，按设备类型归属：
- "塔吊吊运钢筋" → WT08（塔吊优先）
- "脚手架抹灰" → WT07（脚手架优先，抹灰为辅）
- "桥墩混凝土浇筑" → WT09（桥梁优先，混凝土浇筑为辅）

### 规则3：主要目的原则
当作业涉及多个步骤，以主要施工目的为准：
- 管道施工中的沟槽开挖 → 如果目的是铺设管道 → WT11；如果仅是土方工程 → WT01
- 钢结构安装中的焊接 → WT06（钢结构优先）

### 规则4：无法判断时选择 WT15-其他
- 信息不足以判断具体作业类型
- 多工种混合无法区分主次
- 非常罕见的特殊作业类型
