## 决策规则（优先级从高到低，严格执行）

以下规则按优先级排列。对每条文本，从规则1开始依次匹配，首次命中即停止。

```
规则1 [桥梁隧道优先]
  文本涉及桥梁墩台/梁体/桥面/架桥机 → WT08 桥梁工程
  文本涉及隧道/洞室/盾构/顶管/衬砌/暗挖 → WT07 隧道与地下工程

规则2 [起重设备识别]
  文本涉及塔吊/龙门架/井架/施工升降机/汽车吊/履带吊的
  安装/拆卸/顶升/吊运/吊装 → WT06 起重设备安拆与吊装

规则3 [拆除工程判定]
  文本涉及既有建筑物/构筑物（房屋/墙体/烟囱/水塔等）的
  整体或局部拆除/爆破 → WT09 拆除工程
  注意: 模板拆除/脚手架拆除/起重设备拆卸 → 分别归 WT03/WT06

规则4 [模板与脚手架]
  文本涉及模板/支撑架/满堂架/脚手架/操作平台的
  搭设/使用/拆除 → WT03 模板与脚手架工程

规则5 [装饰装修]
  文本涉及抹灰/涂料/保温/幕墙/门窗/防水/贴砖/
  砌筑(非承重)/吊顶/屋面 → WT04 装饰装修工程

规则6 [机电管线]
  文本涉及给排水/燃气/热力/通风/电气/电梯/消防管道/
  市政管线安装(不含沟槽开挖本身) → WT05 机电安装及管线工程

规则7 [主体结构]
  文本涉及混凝土浇筑/振捣/养护/搅拌/泵送/
  钢筋绑扎/加工/连接/预应力张拉/
  钢结构安装/网架/桁架 → WT02 主体结构工程

规则8 [地基基础]
  文本涉及土方开挖/回填/基坑支护/沟槽/
  桩基施工(灌注桩/预制桩/管桩)/地基处理 → WT01 地基与基础工程

规则9 [辅助运输]
  文本涉及设备维修保养/现场清理/巡查检测/
  物料运输搬运/车辆驾驶/临时设施 → WT10 辅助作业与场内运输

规则10 [兜底]
  以上规则均不匹配 → WT99 其他
```

### 关键判定原则

**全生命周期原则**: 设备/工法的安装、使用、维修、拆除归入同一类
- 塔吊的安装/顶升/吊运/拆卸/维修 → 全部归 WT06
- 脚手架的搭设/使用/拆除 → 全部归 WT03
- 模板的支设/使用/拆除 → 全部归 WT03

**工程类型优先原则**: 当施工工艺与工程类型冲突时，工程类型优先
- "桥墩混凝土浇筑" → WT08（桥梁优先于混凝土）
- "隧道锚喷支护" → WT07（隧道优先于支护/混凝土）

**主要目的原则**: 多步骤作业以主要施工目的为准
- "沟槽开挖后铺设管道" → WT05（目的是铺设管道，开挖是辅助步骤）
- "拆除墙体后清运垃圾" → WT09（拆除是主体，清运是辅助步骤）

**设备操作 vs 辅助运输的区分**:
- 起重设备的专业操作（吊运、顶升等）→ WT06
- 通用车辆/机械的驾驶操作（铲车、叉车、运输车）→ WT10

### WT01 地基与基础工程

**代码**: WT01  
**名称**: 地基与基础工程  
**样本量**: 235个唯一值 / 248条记录（11.3%）  
**事故高发类型**: 土方坍塌（58%）、坍塌（17%）、触电（5%）

#### 定义范围

以地基和基础为主要施工对象的作业活动，涵盖从自然地坪以下到基础顶面的全部土建工作。

#### 包含的作业类型

| 子类 | 具体内容 | 典型原始文本示例 |
|------|---------|----------------|
| 土方开挖 | 基坑/基槽/沟槽/大面积土方开挖、人工挖土、机械挖土 | `土方开挖`、`挖地基`、`沟槽开挖`、`基坑施工` |
| 土方回填 | 基础回填、房心回填、场地回填、压实 | `回填土`、`夯填作业` |
| 基坑支护 | 排桩、地下连续墙、水泥土墙、土钉墙、锚杆/锚索、内支撑 | `深基坑支护`、`锚杆钻孔作业`、`基坑护坡` |
| 降水排水 | 井点降水、集水坑排水 | `基坑降水`、`排水沟开挖` |
| 桩基施工 | 灌注桩（钻孔/冲孔/旋挖）、预制桩（锤击/静压）、CFG桩、搅拌桩、碎石桩 | `打桩作业`、`人工挖孔桩作业`、`钻孔灌注桩`、`CFG桩施工` |
| 地基处理 | 强夯、换填、预压、振冲、深层搅拌（非桩基类） | `地基施工`、`强夯作业`、`地基加固` |
| 边坡工程 | 自然边坡/人工边坡的开挖、加固、防护 | `人工切坡作业` |

#### 边界说明

- **管道沟槽开挖** → 如果明确目的为管道铺设 → WT05；仅描述挖沟过程无管道作业 → WT01
- **桥墩桩基** → WT08（桥梁优先）
- **锚杆/锚索施工** → 用于基坑支护 → WT01；用于隧道支护 → WT07；用于边坡加固 → WT01
- **污水/雨水管沟开挖并存** → 有管道安装描述 → WT05；仅有开挖 → WT01

#### 典型事故模式

土方坍塌掩埋（沟槽/基坑边坡失稳）、基坑支撑体系失效、桩机倾覆、强夯飞石打击

### WT02 主体结构工程

**代码**: WT02  
**名称**: 主体结构工程  
**样本量**: 316个唯一值 / 397条记录（18.0%）  
**事故高发类型**: 坍塌（69%）、高处坠落（9%）、触电（7%）

#### 定义范围

以建筑物的承重骨架和竖向/水平受力构件为主要施工对象的作业活动，是建筑物从基础顶面到屋顶的结构施工全过程。

#### 包含的作业类型

| 子类 | 具体内容 | 典型原始文本示例 |
|------|---------|----------------|
| 混凝土浇筑 | 搅拌、运输（塔吊吊运除外）、泵送、浇筑入模、振捣、找平、养护 | `浇筑混凝土`(27次)、`混凝土浇灌`、`泵送混凝土`、`封顶施工`、`现浇封顶` |
| 混凝土预制构件安装 | 预制楼板/楼梯/墙板/梁柱的吊装就位 | `安装楼板`、`预制板安装` |
| 钢筋工程 | 调直、切断、弯曲成型、绑扎、焊接连接、机械连接、钢筋笼制作/吊装 | `绑钢筋`、`绑扎钢筋`、`钢筋加工`、`钢筋笼吊装` |
| 预应力工程 | 先张法/后张法预应力筋张拉、锚固、孔道灌浆 | `预应力张拉`、`预应力筋穿束` |
| 钢结构安装 | 钢柱/钢梁/钢桁架/钢屋架的吊装、拼装、螺栓连接、焊接 | `钢结构施工`、`钢网架高空散拼安装`(2次) |
| 网架/网壳 | 高空散拼、整体吊装、整体提升、滑移 | `网架安装`、`钢屋架吊装` |
| 组合结构 | 型钢混凝土柱/梁、钢管混凝土 | `钢管柱混凝土浇筑` |

#### 边界说明

- **混凝土搅拌机操作**（无浇筑上下文）→ 可能归 WT10（辅助作业）
- **塔吊吊运混凝土/钢筋** → WT06（设备优先于材料）
- **桥墩/箱梁混凝土** → WT08（桥梁优先）
- **隧道衬砌混凝土** → WT07（隧道优先）
- **彩钢板/轻钢结构** → 如果是主体承重结构 → WT02；如果是围护/分隔 → WT04

#### 与 WT01 的区分

- 地基基础(WTO1) 作业面在地面以下，以土/岩/桩为对象
- 主体结构(WTO2) 作业面在地面以上，以混凝土/钢筋/钢构件为对象
- 临界：地下室底板浇筑 → WT02（结构构件）；地基垫层浇筑 → WT01（地基处理）

#### 典型事故模式

模板坍塌（混凝土浇筑时）、钢结构失稳坍塌、钢筋笼倾覆、预应力筋断裂回弹

### WT03 模板与脚手架工程

**代码**: WT03  
**名称**: 模板与脚手架工程  
**样本量**: 168个唯一值 / 203条记录（9.2%）  
**事故高发类型**: 高处坠落（~40%）、坍塌（~40%）

#### 定义范围

为混凝土浇筑提供成型模具（模板）和为施工作业提供竖向/水平通道与操作面（脚手架/平台）的临时设施工程。**v2.0 将原 v1.0 的 WT04（模板与支撑）和 WT07（脚手架作业）合并**，因为在事故文本中两者的作业描述和事故特征几乎无法可靠区分。

#### 包含的作业类型

| 子类 | 具体内容 | 典型原始文本示例 |
|------|---------|----------------|
| 模板搭设与拆除 | 柱模/梁模/板模/墙模的支设、加固、拆除 | `模板施工`、`拆除模板`(3次)、`拆模作业`、`支模` |
| 支撑体系 | 满堂架、承重架、排架、高支模（扣件式/碗扣式/盘扣式）的搭设与拆除 | `支模架搭设`、`拆除支模架`、`高支模架施工` |
| 操作平台 | 施工作业平台、卸料平台的搭设、使用、拆除 | `搭设操作平台` |
| 外脚手架 | 落地式/悬挑式/附着式外脚手架的搭设、使用、拆除 | `搭设脚手架`(6次)、`脚手架拆除`(3次)、`脚手架作业`(7次)、`外脚手架拆除` |
| 爬架 | 附着式升降脚手架（爬架）的安装、提升、下降、拆除 | `附着式脚手架下降作业` |
| 防护设施 | 防护棚、安全通道、临边防护栏杆 | `防护棚防护板铺设` |
| 钢模板 | 组合钢模板/大钢模的安装与拆除 | `拆除钢模板` |

#### 边界说明

- **模板/脚手架与其他工种的交叉**: 模板上浇筑混凝土时的事故 → WT03（模板是事故直接相关作业）
- **模板拆除 vs 结构拆除**: 拆模板为周转使用 → WT03；拆墙体/楼板为建筑物拆除 → WT09
- **塔吊配合模板吊运**: 塔吊司机作业 → WT06；模板工在作业面操作 → WT03
- **卸料平台**: 为脚手架体系的一部分 → WT03

#### 典型事故模式

模板支撑体系坍塌（混凝土浇筑荷载超限）、脚手架整体倾覆或局部坍塌、从脚手架/模板作业面高处坠落、操作平台断裂

### WT04 装饰装修工程

**代码**: WT04  
**名称**: 装饰装修工程  
**样本量**: 238个唯一值 / 254条记录（11.5%）  
**事故高发类型**: 高处坠落（44%）、坍塌（36%）、起重伤害（7%）

#### 定义范围

以建筑物内外表面处理、美化、功能提升为主要目的的作业活动，包括墙面、地面、顶面的装饰施工和建筑围护体系的安装。

#### 包含的作业类型

| 子类 | 具体内容 | 典型原始文本示例 |
|------|---------|----------------|
| 抹灰/粉刷/涂料 | 内墙/外墙/顶棚的底层、面层抹灰及涂饰 | `抹灰作业`(3次)、`外墙抹灰`、`粉刷作业`、`刷白` |
| 外墙保温 | 保温板粘贴/锚固、保温砂浆、保温装饰一体板 | `外墙保温施工`(3次)、`外墙保温装饰板修补及打胶勾缝` |
| 幕墙安装 | 玻璃幕墙/石材幕墙/金属幕墙（含龙骨安装） | `幕墙安装`、`安装玻璃` |
| 门窗安装 | 铝合金/塑钢/钢质门窗及防火门/卷帘门安装 | `门窗安装` |
| 屋面工程 | 屋面防水/保温/找平/瓦屋面/金属屋面 | `屋面施工`、`屋面防水`、`铺设屋面瓦`、`屋面保温` |
| 防水工程 | 地下室/卫生间/屋面/外墙防水层施工 | `防水工程施工`、`防水层铺设`、`铺贴油毡防水` |
| 贴砖/石材 | 墙地砖铺贴、石材干挂/湿贴、踢脚线 | `贴瓷砖`、`贴外墙面砖`、`镶贴外墙装饰砖` |
| 砌筑（非承重） | 填充墙（加气块/空心砖）、隔墙砌筑 | `砌砖`、`砌体施工` |
| 吊顶/隔断/地板 | 轻钢龙骨吊顶、轻质隔墙、木地板/复合地板 | `吊顶施工`、`地板铺设` |
| 外立面改造/整修 | 既有建筑外墙翻新、清洗、修补 | `外立面装修`、`外墙整修施工`、`外墙装修` |

#### 边界说明

- **砌筑（承重墙 vs 填充墙）**: 填充墙砌筑 → WT04；承重墙/结构砌体（如砖混结构墙体）→ WT02
- **屋面**: 屋面防水/保温/瓦 → WT04；屋面结构混凝土浇筑 → WT02
- **房屋整修**: 以装饰翻新为主 → WT04；以结构加固为主 → WT10（维修加固）
- **幕墙龙骨**: 幕墙安装的一部分 → WT04；纯钢结构骨架 → 如果是幕墙体系 → WT04

#### 与 WT02（主体结构）的区分

- 主体结构(WT02)以承重/受力为目的 → 混凝土/钢筋/钢结构
- 装饰装修(WT04)以美观/围护/功能为目的 → 抹灰/涂料/幕墙/砌填充墙
- 临界：彩钢板安装 → 屋面围护 → WT04；钢结构厂房屋面梁 → WT02

#### 典型事故模式

外墙作业高处坠落（吊篮/脚手架）、幕墙玻璃/石材板块坠落、屋面作业滑落、保温材料火灾

### WT05 机电安装及管线工程

**代码**: WT05  
**名称**: 机电安装及管线工程  
**样本量**: 148个唯一值 / 150条记录（6.8%）  
**事故高发类型**: 土方坍塌（43%）、高处坠落（18%）、中毒窒息（11%）

#### 定义范围

以建筑设备和市政管线的安装、连接、调试为主要目的的作业活动，涵盖建筑给排水、暖通空调、电气、消防、电梯及室外市政管线的施工。**v2.0 将原 v1.0 的 WT11（管道与管网）和 WT14（设备安装）合并**，两者同属 MEP（机械、电气、管道）范畴。

#### 包含的作业类型

| 子类 | 具体内容 | 典型原始文本示例 |
|------|---------|----------------|
| 给排水管道 | 室内给水/排水/雨水管道安装，室外给水管网/污水管网/雨水管网施工 | `污水管网施工`(2次)、`铺设污水管道`、`铺设下水管道` |

### WT99 其他

**代码**: WT99  
**名称**: 其他  
**样本量**: 61个唯一值 / 63条记录（2.9%）

#### 适用范围

以下情况归入 WT99：
1. **跨类混合**: 同一文本中涉及 3 种以上不同工序，无法判断主要作业类型
2. **非建筑施工**: 明确不属于建筑施工范畴（矿山、工厂生产、体育训练、文娱活动等）
3. **信息严重不足**: 仅有"施工""作业"等通用词，无法做任何工序推断
4. **罕见专业作业**: 施工行业中极少见的特殊作业类型（如筑炉、煅烧窑衬砌等）

#### 典型示例

| `施工作业`(2次) | 信息不足，无法推断具体工序 |
| `房屋建造施工`(2次) | 信息不足 |
| `职工歌咏比赛彩排` | 非建筑施工活动 |
| `美式足球训练` | 非建筑施工活动 |
| `非法改建窑体` | 罕见特殊作业（工业窑炉） |
| `采沙作业` | 矿产资源开采，非建筑施工 |
| `筑炉作业` | 工业炉窑砌筑，罕见专业 |
| `调试爆破用炸药` | 非施工爆破（可能为采矿/采石） |
